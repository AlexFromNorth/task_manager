## Getting Started

Если необходимо запустить проект, необходимо прописать:

```bash
yarn 
# then
npm run dev
# or
yarn dev
```
- проект откроется по пути http://localhost:3000/i и должен попросить авторизации, поэтому сперва стоит выполнить этапы из readme back-end

----

Для создание прод версии и последующего просмотра необходимо прописать:

```bash
yarn build
# then
yarn start 
```
